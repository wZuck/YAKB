# EC 驱动修补与复现

[English](README.md)

west 继续锁定上游 `bcb61bdee0a548976bea8f376f8cdec6b4ffd5fe`。编译任一固件前，在 YAKB 仓库运行 `python3 scripts/prepare_firmware.py --workspace /绝对路径/west工作区`。脚本核对提交、修改前后 SHA256，应用一次补丁并复制键盘配置；重复执行安全，未知修改会报错。

补丁在第一次原始状态变化时恢复快速扫描，保留连续两帧确认按下；未经确认的短脉冲释放后也重新计时空闲。校准高低值相等或颠倒时直接拒绝，避免除零。配置采用 4/8/12 ms 等待间隔，合作式优先级参数为 `15`（16 级配置下实际为 `-1`），启用内核断言。

CI 编译普通版和校准版，并使用真实修补后 C 函数、模拟 ADC/GPIO 测试 960 组相位/帧耗时组合、60 键屏蔽与同时按下/释放、瞬态恢复和无效校准。这些是逻辑回归，不是实测延迟或功耗。上游源码保留原 SPDX/许可标记；补丁单独交付，不把修补后的源码伪称为未修改的固定上游提交。

追加保护：校准阶段若 20 次空载 ADC 值相同，实测噪声为零；只将 SNR 估计的分母限制为至少 1 ADC count，保留真实噪声记录。测试直接提取上游 `sample()` 和 `calibrate()`，使用恒定低/高输入及未定义行为检查器验证该边界。
