# YAKB A0 PCB 加工说明

B1.1 沿用本页主板加工文件，但主板 U1 不装主控；还需 [B1 模块化文件](../docs/modular/README.zh-CN.md)中的两张刚性板和定制 FPC。此目录的 A0 壳体 USB 延长方案不能用于 B1.1 装配。

[English](README.md) · [检查结果](../reports/design-checks.json) · [焊接工作台](../hardware/soldering/index.html)

本目录包含完整 Gerber 和 PTH/NPTH 钻孔文件，来自通过原生检查的 `hardware/YAKB.kicad_pcb`。这是尚未打板的工程原型，先做小批首板与机构试片，完成电气和装配测量后再扩大制造。

| 项目 | 规格 |
| --- | --- |
| 外框 | 285.0×94.6 mm、R2，含左右开口槽、内部矩形和安装孔槽 |
| 铜层数 | **4 层，顺序 F.Cu → In1.Cu → In2.Cu → B.Cu** |
| 总厚 | 标称 1.6 mm；FR4 |
| 规划叠层 | 铜各 0.035 mm；介质 0.20 / 1.04 / 0.20 mm；两面阻焊各 0.01 mm，合计 1.6 mm |
| 铜/介质约束 | 规划值，交工厂核对可生产的 1.6 mm 标准叠层；不要求阻抗控制。实际介质会影响 EC，首板须校准 |
| 走线 | 常规 0.2 mm，局部最小 0.15 mm |
| 铜间距 / 铜到板边 | 最小 0.20 / 0.25 mm |
| 过孔 | 常规 Ø0.60 / 钻 Ø0.30；前端逃线局部 Ø0.45 / 钻 Ø0.25；最小环宽 0.10 mm |
| 工艺 | 所有过孔均为贯通孔；无盲埋孔、背钻或阻抗要求 |
| 阻焊 | 两面绿色为默认；感应电极保留阻焊覆盖，不开钢网口、不上锡 |
| 内层 | 感应中心半径 6 mm 范围禁止走线/铺铜；没有整面内层电源/地平面 |
| 天线 | 右前区所有铜层禁布，不能随意加铜或覆盖金属 |

`YAKB-In1_Cu.g1` 和 `YAKB-In2_Cu.g2` 都必须上传，不能当成普通双面板漏掉内层。孔文件分为 PTH 与 NPTH；椭圆孔使用铣槽输出，左下大避让及侧面开口保留在 Edge.Cuts。让工厂按完整轮廓处理，不能把开口槽自动补成矩形边。

B.Paste 提供给需要手动钢网的人；默认可以按中文指南手焊，主控和开关接线孔为通孔。不要把感应电极当作焊盘镀锡。JST 接头极性必须实测，软包电池包含保护板和线出口后的外包络需满足设计。

Gerber 只包含 PCB；不包含 NiZ 轴壳、滑块、胶碗、感应锥簧、键帽、稳定器、电池、主控模块、插座、线缆和壳体。完整手工采购见 BOM 和设计说明。正式定位板加工前务必用相同材料完成 NiZ/稳定器试片。
