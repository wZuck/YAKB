# YAKB A0 设计复查与修复记录

本次复查覆盖保存的 PCB、真实器件模型、机械包络、EC 驱动和发布产物。以下是已修复并检查的缺陷；A0 仍是待实物验证的原型。

| 问题 | 修复与证据 |
|---|---|
| 30 个通孔焊盘被阻焊覆盖，底层库共享铜层集合被意外修改 | 复制层集合后增加双面阻焊开窗；原生焊盘和两面 Gerber 均核对 30 个开窗，EC 电极保持覆阻焊且无锡膏 |
| 主控 USB 实际朝向与外壳假设相反 | 修正 U1 方向、模块和 USB 插头包络，并核对 1/24 脚位置 |
| USB 插头与 U4 碰撞，横梁与 R33/C1 碰撞 | 移动 U4/C3 并重布相关线路；横梁增加两个让位槽；原生器件实体与外壳相交检查通过 |
| 电池连接器缺乏可采购的明确方向型号；MUX 料号错误 | J1 固定水平 JST S2B-PH-K；MUX 固定 TI CD74HC4051M96，原理图、BOM、PCB、指南同步 |
| 顶面可见螺丝 | 改为 8 颗底部锁入 M2，顶框盲孔嵌件；后20/侧18/前16 mm，顶面连续，定位板增加真实避让槽 |
| 定位板覆盖天线投影区域 | 定位板增加 21×16 mm 无金属窗口；优先无铜 FR4/G10；金属外壳的射频效果仍需单独验证 |
| 慢轮询首键和释放可能延迟；校准零噪声可能除零 | 原始转换立即回到快速扫描；释放重置空闲计时；无效校准拒绝；SNR 除数下限为1且保留实际零噪声值 |
| 固件包可能脱离当前驱动/配置 | 两种 UF2 重新构建，包装核对驱动、对象时序、DTS、ELF 有效段和 UF2 字节；保留输入 SHA256 |
| 渲染泛白、示意几何容易与文件脱节 | Cycles 软光与受控曝光；3D 读取保存 STEP/原生 GLB，2D 读取实际 DXF/铜箔；28 项输出记录来源与图像哈希 |

## 验证范围

- 原生 ERC、DRC（包含原理图一致性）、未连接网络均为 0；309 个实际引脚交叉核对。
- 37 个实际库器件模型参与检查；主控、电池、USB 插头与键帽使用明确标注的包络。16 组核心机械相交检查为 0，不包含尚未取得的 NiZ 内部实物。
- 正常版与校准版实际构建成功，USB 与 BLE 均启用。Fn+5 选择 USB，Fn+6 选择 BLE，同一时刻向一个端点发送按键。
- EC 实际驱动函数通过 960 组按键时相/帧时长组合、60 键有效掩码与释放测试、无效校准、恒定 ADC 零噪声校准测试。28 ms 是模型内首次报告上界，不是实测延迟保证。
- 三个 60×35×5.5 mm 电芯包络可放入现有高度；可选底壳和共享保护板包络已交付。标称容量是选型目标，不能据此外推任意电池都适配。
- `scripts/verify_release.py` 检查渲染来源、PCB 报告、Gerber ZIP 和 UF2 的一致性。

## 首件仍需解决的不确定性

高阻 SENSE 网络的走线分支累计约 162.1 mm，ADC 约 58.7 mm；DRC 通过不等于模拟噪声足够小。需实测按下/释放信号、充电噪声、USB 线影响、BLE/Wi-Fi 共存和电池电流。若信号余量不足，进一步收拢 MUX/运放/反馈并重新布线，不能靠软件阈值掩盖问题。

NiZ 卡扣、胶碗预压、6u 稳定器、第三方 GH60 外壳柱位及最终电池型号仍需试片/样件确认。续航为模型估计；多电芯必须由厂商提供匹配、保护完整的 1S 电池包。完整检查条件见电气分析与兼容性文档。

## 2026-10-23 装配复核

修复了原生CAD与渲染之间的Y轴镜像差异；交付STEP/STL/DXF改为X右/Y后/Z上的右手坐标，并增加实际实体方向检查及正面俯视图。

USB仍有未闭合项：左后外壳开口与右前主控不直接对齐，原设计只检查局部插头包络，未交付完整延长线与母口固定结构。不能据局部报告认定闭壳USB可装配。详见[接口状态](assembly-interface.zh-CN.md)。
