# YAKB A0 焊接与装配顺序


[打开离线交互焊接工作台](../hardware/soldering/index.html)：18 步高亮定位图、元件筛选、完成度保存、图片放大与打印。

适用对象：通过当前电气文件检查后制作的 YAKB A0 工程样机。**当前未有实物焊接成功记录**；本文是设计对应的首件操作流程。先完成试片，再采购 / 加工完整机构。所有测量均以实际原理图网络和元件引脚为准，不能根据图片颜色判断正负极。

## 0. 准备与认方向

准备细头恒温烙铁、助焊剂、细焊锡、镊子、放大镜或显微镜、吸锡带、万用表、可限流的 USB 供电装置、USB 数据线；调试 EC 还需要示波器，测续航建议使用电流分析仪。烙铁温度按焊锡和器件资料设置，以能迅速润湿为准，避免长时间压住焊盘。

感应电极在正面 F.Cu，电子元件主要在背面 B.Cu。装主控时 USB 口朝 PCB 左侧，位于右下角空白区；它通过内部 USB 数据延长组件连接外壳左后侧。背面图要从实际焊接面看，**不要再额外镜像一次**。

NiZ 机构没有需要逐键焊接的金属触点。弹簧区保持阻焊原状，禁止刷锡或把弹簧焊到电极。电池、胶碗、轴壳和键帽在焊接 / 清洗阶段全部移开。

## 1. 先做机械试片

打印 `niz_fit_coupon.stl` 做粗试装，再用正式材料 / 厚度做同样的开孔试片。比较 13.9 / 14.0 / 14.1 mm 孔，确认轴壳卡扣、方向、滑块回弹与卫星轴卡扣。确认 6u 空格为中心十字接口、卫星轴中心间距 95.25 mm；2.25u 大键为 23.8125 mm。

不通过就修改尺寸源和生成脚本，重新生成定位板及验证报告。不能用拧紧整机、强压胶碗或加厚泡棉来补救错孔和错高度。

## 2. 裸板检查

1. 确认 PCB 版本、尺寸、板厚、感应面阻焊、全部安装槽和 60 个感应单元。检查运输变形、铜屑、断线和孔壁毛刺。
2. 用万用表检查 VCC-GND、BAT_RAW-GND、BAT_SW-GND 和 AFE_3V3-GND 是否明显短路。裸板不能持续显示近 0Ω。
3. 核对 U2/U3 的 1 脚、U4 的 1 脚、Q1 的 G/S/D、U1 的 USB 方向及 J1 极性。两种 SOIC 芯片不能互换。
4. 对照 PCB 背面图和 BOM 备料。0805 是英制尺寸（公制 2012）；220pF 必须使用 C0G/NP0，不拿 220nF 替代。

**本阶段不插主控、不接 USB、不接电池。**

## 3. 先焊低矮的 0805 阻容

先在一侧焊盘预上少量锡，镊子放件，熔化后摆正，最后焊另一侧。按器件组完成后逐组核对，避免把 100Ω / 1k / 100k 混放。

| 顺序 | 位号 | 数值 / 检查 |
| --- | --- | --- |
| 3A | R1…R5 | 100Ω，5 路行激励串联电阻 |
| 3B | R10…R24 | 100kΩ，15 列泄放 |
| 3C | R30 | 100kΩ，反馈 |
| 3D | R31、R32、R36 | 1kΩ，分别为增益下臂、放电限流、栅极串联 |
| 3E | R33、R34、R35 | 100kΩ，MUX 禁用及 P 管关断上拉 |
| 3F | C1、C2、C3 | 100nF，各芯片去耦 |
| 3G | C4 | 220pF C0G/NP0，采样电容 |
| 3H | C5 | 1µF，VCC 本地去耦 |

全部电阻和本版陶瓷电容无极性。焊完复查无立碑、虚焊和锡桥。在线测阻会受其他电阻路径影响；有疑问时抬起一端或焊前测值，不能据此盲目更换正常器件。

## 4. 再焊三个 SOIC 芯片和 Q1

顺序：U2、U3（CD74HC4051M96）→ U4（OPA350UA）→ Q1（AO3401A）。先固定两个对角引脚，确认器件平整、1 脚方向正确，再逐脚焊接。使用足够助焊剂；有锡桥时用吸锡带处理后放大检查。

- U2/U3：16=VCC，8=GND，7=VEE（本版接 GND），6=INH，3=COM。**OPA350 不是 4051。**
- U4：7=AFE_3V3，4=GND，3=正输入 SENSE，2=负输入 FB，6=输出 ADC；1/5/8 不连接。
- Q1：1=GATE，2=SOURCE/VCC，3=DRAIN/AFE_3V3。检查采购料号和厂家引脚图，不凭 SOT-23 外观猜脚位。

用蜂鸣档检查相邻引脚是否意外桥连；同网络的相邻脚响是正常现象，应与原理图核对。确认 VCC-GND 无持续低阻后再进入下一步。

## 5. 焊接通孔、开关线和主控插座

1. 焊 J1 的 水平 JST S2B-PH-K，2.0 mm 电池座。PCB 定义 **1=BAT_RAW 正极、2=GND**；配套插头线序不是跨品牌统一标准。
2. SW1 是两个 2.54 mm 间距接线孔，用短绝缘线串接一个 SPST 实体开关：1=BAT_RAW，2=BAT_SW。它不是某个滑动开关的精确焊盘。开关固定在底部检修窗口附近，导线应有应力释放。
3. SW2 是 Reset 与 GND 的两孔线位，可接常开瞬时按钮；也可保留给断电后的检修短接。不要把常闭开关焊在这里。
4. 安装两排 12 针低矮插座。可以用未通电的主控或直排针夹具校正平行度，先焊四角，再焊其余引脚；取下主控后检查是否桥连。
5. 所有焊脚修齐。确认控制器插座加模块的总下凸量不超过 6.5 mm。普通高脚排母、排针叠装可能超高，不能按模型净空硬压安装。

主控模块上的晶振、天线、充电器、USB-C 和细间距 MCU **不需要用户重焊**。默认不桥接 BOOST。电池继续保持未连接。

## 6. 清洗和最终断电检查

按助焊剂说明清洁，尤其是 SENSE、C4、U4 输入、MUX 列输入附近；清洁剂不能留在胶碗、轴壳或电池上。完全干燥后再检查。VCC-GND 阻值短暂变化可能来自电容充电，持续接近 0Ω 才是需立即排查的情况。

核对所有值、1 脚、J1 极性、主控方向和电源开关导通 / 断开。用万用表确认开关关闭时 BAT_RAW 与 BAT_SW 隔离、开启时导通。此时尚不安装感应机构。

## 7. 首次通电：只有 USB，没有电池

插入主控，用具有数据功能且可限流的 USB 供电装置，首次电流限值可从 100 mA 起。若触发限流、器件明显发热或电压异常，立即断开排查；不要接电池来“试试看”。先直接接模块 USB-C，确认后再接内部延长线，以便区分板级故障和线材故障。

以下测量点均是**现有元件引脚 / 焊盘**，不是声称 PCB 另有相同编号的测试点：

| 网络 | 方便的测量位置 | 预期 |
| --- | --- | --- |
| GND | U1-23 或 J1-2 | 所有电压测量参考 |
| VCC | U1-21、U2-16、U3-16 | 模块启用外部电源后的标称 3.3V |
| AFE_GATE | Q1-1 | 高=运放关断；低=开启 |
| AFE_3V3 | U4-7、Q1-3 | 仅扫描 / 校准期间有电，示波器观察 |
| MUX0_INH / MUX1_INH | U2-6 / U3-6 | 高禁用；不能同时低 |
| SENSE | C4-1、U4-3 | 充放电小信号；高阻探头测量 |
| ADC | U4-6、U1-18（D19） | 目标范围 0…3.3V，不应长期饱和 |
| DRAIN | R32-1（主控侧） | 放电时低、采样时高阻 |

未开启 EC 扫描时 AFE_3V3=0V 可以是正常状态；万用表在脉冲供电时看到的是平均值，不能用它代替波形。SENSE 极敏感，探头也会改变电容，使用适当低电容探头并记录测量条件。

## 8. 固件与四键试装

先刷入与当前 GPIO 完全一致的固件。双击模块 Reset 可进入 UF2 bootloader；必须核对构建目标与当前提交。不要把其他键盘固件当作电气自检程序使用。

先只装一小组（例如 Esc、1、2、3）的轴壳、胶碗和锥簧，用定位板固定到设计高度。在启用校准器的版本中，先用 `ec` 命令补全检查设备名；执行该设备的 `calibration start`，按提示空载和逐键采样，确认后 `save`，重新上电 `load` / 冷启动复核。完整 60 键校准随后进行，测试配置中的 mask 应对应当时实际装配位置。

检查按下 / 释放动态范围、噪声和迟滞，观察慢压、快速点按、同时按键、长按及电源切换。未经测试，不要直接压低阈值追求更短触发距离。

## 9. USB 稳定后才接电池

1. 断开 USB，实体开关关闭，模块断电。检查电芯外包络（包括保护板、包膜及线出口）不超过 60 × 35 × 5.5 mm；容量标签不能替代尺寸测量。
2. 测量插头对应 J1-1 相对 J1-2 为正电压。若极性反向，先修正线序；带保护电池不等于板级反接保护。
3. 插入电池，打开开关，先测 VCC 和工作电流，再测试蓝牙。没有异常才接 USB 验证充电及温升。
4. 默认充电约 100 mA。BOOST 保持未桥接。开关关闭会切断充电路径，充电时开关需开启。
5. 电池置于独立仓内，底部绝缘并保留余量；固定线材而不挤压电芯，不在电池上方留尖锐焊脚、螺钉尖或金属毛刺。

## 10. 最后安装全部机构和外壳

取下电池和 USB 再装机构。将 NiZ 壳按确认方向卡入定位板；清洁锥簧、放入匹配胶碗和弹簧，使锥簧自然落在电极中心。不能让锥簧跨到另一电极或被螺丝压住。

安装板装卫星轴和经过验证的 6u 空格。用最小必要固定点轻轻合拢结构，确认板间高度和平整度；逐键试压后再逐步均匀固定。中央托盘柱、螺丝头和胶碗有干涉时，不能硬锁，应修改适配结构。

先测试裸壳内蓝牙，再盖上框；金属外壳必须另验天线窗口。整理 USB 数据延长线，不在模块口施加侧向力；固定电池后重新接入供电，完成所有 60 键校准与冷启动验证。

## 11. 记录首件结果

记录试片选定孔径、卫星轴品牌 / 6u 规格、板间距、USB 组件型号、真实电池尺寸、焊接问题、校准数据、充电温升和六种供电 / 工作状态电流。检查持续按键后释放、BLE 切换、断电重启、USB 插拔、快速首键和大键回弹。将结果加入首件报告后才能把“设计预期”改成“实测通过”。

## 隐藏外壳螺丝与主控方向

正面坐标中 U1 在右下、USB 朝左；指南背面图已经镜像，所以图中 U1 在左、USB 朝右，不要再次镜像。运放 ADC 逃线有 0.25 mm 钻孔过孔靠近焊盘，焊后检查吸锡和虚焊。

上框从底面装入 8 颗 M2 热熔螺母，名义外径 3.2 mm、长 3 mm，先验证 3.0 mm 盲孔的热熔配合；保留正面完整表皮。外壳均从底部锁入：后排 3 颗 M2×20、左右侧 2 颗 M2×18、前排 3 颗 M2×16。螺钉头最大 Ø3.8×2 mm，模型螺纹啮合 3 mm、头部至少缩入底面 0.94 mm。不要混装长度或使用更长螺丝。定位板边缘缺口给上框螺母柱让位；PCB 支柱的 3.3 mm 螺母孔属于另一套固定点。天线开窗区域不得放线缆、金属箔或金属胶带。
