检查包括：全部 Git 管理及本次新增交付文件的 SHA256 清单；JSON / CSV / Python 解析、ZIP CRC、PNG 解码、GLB / UF2 / STL / STEP / PDF 格式完整性、XML 与 DXF 解析；文档 / HTML 本地链接；逐项 BOM / 指南 / 原生封装坐标；FPC 24 路；主板及四张模块板原生 ERC/DRC；既有机械、渲染、加工 ZIP、固件哈希验证。机器报告逐文件列出实际执行的检查，不把格式检查写成全部工程性质证明。

复核命令：先用 KiCad Python 运行 `verify_modular.py` 刷新原生提取，再用项目 Python 运行 `verify_release.py`、`verify_modular_release.py`、`verify_repository.py --native`。内容修改后按[复现文档](reproduce.zh-CN.md)刷新对应产物，不能只重写哈希来消除过期提示。

未完成项仍是实物试验：NiZ / 稳定器配合、FPC 接触与锁止、USB 真实高度及插拔受力、扫描 / 充电噪声、蓝牙干扰、温升与续航。浏览器安全策略未允许本次打开本地指南页面，故未声称完成浏览器交互验收；已检查交付 HTML / JS、链接、数据和生成图片。
